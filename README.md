# Домашнее задание (TypeScript)

Проверка совершеннолетия пользователя с помощью типизированной функции `checkAge`.

## Структура проекта

- `age.ts` — функция `checkAge(age: number): boolean` и тестовые вызовы.

## Ветки репозитория

- `main` — основная стабильная ветка
- `dev` — ветка для разработки
